# Dashboard screenshots

Made by `python scripts/screenshot_dashboard.py` (Playwright, Chromium, 1366×768): the app is launched,
each page is opened, and the Live Detection page is captured after running the detector on the bundled
sample clip. `<page>.png` is the whole page, `<page>_viewport.png` the first screen; `results_2.png` to
`results_5.png` are the other tabs of the Results page (Ambulances, Model size, Camera errors, Detector).
The FPS numbers in `live_detection*.png` were measured on the GTX 1650 when the screenshots were taken.
