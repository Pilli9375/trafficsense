# IEEE conference paper

`paper.tex` is a six-page IEEE conference paper (`\documentclass[conference]{IEEEtran}`) condensed
from the report in `docs/report/`: the same numbers and the same labels (pre-registered,
exploratory, post-hoc), nothing new. `paper.pdf` is the built paper; `paper_overleaf.zip` is the
same sources packed for Overleaf.

```bash
python scripts/make_paper.py                # refresh tables, figures and tagged numbers; build PDF and zip
python scripts/make_paper.py --check        # fail if anything differs from outputs/ (also run by pytest)
python scripts/make_paper.py --pages 1,3,5  # also render those pages to build/pages/ (git-ignored)
```

**How numbers are tied to the data.** As in the report, with LaTeX syntax: a number from the data
is written `\V{f.off.mp.att}{88.1}` (the macro prints `88.1` and ignores the key). Tables sit
between `% BEGIN:name` and `% END:name` and are generated by `src/trafficsense/report/paper.py`;
figures (`figures/*.pdf`, vector, 3.5 in wide) are drawn by
`src/trafficsense/report/paper_figures.py` from the same data as the report's figures, each with
a `.data.json`. The check fails on any untagged number in the body, a stale table or figure,
a mismatch, a citation that is not one of the report's verified references, an abstract outside
150–250 words, a PDF or zip not built from the current sources, or more than 6 pages.
Registration numbers and the capstone term are identifiers, listed one by one in
`paper.IDENTIFIERS`; any other registration-number-shaped token fails the check.

**Build.** Tectonic (XeTeX) in `~/.local/bin`; the build also fails on overfull lines and
undefined references or citations. The source is plain ASCII and loads only standard packages
(`newtxtext`/`newtxmath`, `booktabs`, `graphicx`, `amsmath`, `cite`, `url`, `iftex`), so it should
also compile with pdfLaTeX, Overleaf's default; it has only been built locally with Tectonic.

## Before submitting: fill in the placeholders

At the top of `paper.tex`:

* `\EmailA` … `\EmailD`: the four authors' e-mail addresses (currently `{{EMAIL1}}` … `{{EMAIL4}}`).
* `\CapstoneID`: the capstone ID (currently `{{CAPSTONE_ID}}`; the diary reads `3328F4C8` but the
  handwriting is unclear, so confirm it first).

Then run `python scripts/make_paper.py` to rebuild the PDF and the zip, or edit on Overleaf.
The author block gives the city as Amaravati; check it against your university's style.

## Compiling on Overleaf

1. Overleaf → **New Project** → **Upload Project** → choose `paper_overleaf.zip`.
2. Open **Menu** and check **Compiler: pdfLaTeX** and **Main document: paper.tex**
   (Overleaf has `IEEEtran.cls` and `IEEEtran.bst` built in, so the zip does not include them).
3. Click **Recompile**. Overleaf runs BibTeX itself; if references show as `[?]`, recompile once
   more.
4. Fill in the placeholders (above) in `paper.tex` and recompile.

Edits made on Overleaf are not checked against `outputs/`. To keep the guarantee, copy the edited
`paper.tex` back here and run `python scripts/make_paper.py --check`.
