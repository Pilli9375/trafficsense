# IEEE conference paper

`paper.tex` is an IEEE conference paper of at most eight pages including references (`\documentclass[conference]{IEEEtran}`) condensed
from the report in `docs/report/`: the same numbers and the same labels (pre-registered,
exploratory, post-hoc), nothing new. `paper.pdf` is the built paper; `paper_overleaf.zip` is the
same sources packed for Overleaf.

```bash
python scripts/make_paper.py                # refresh tables, figures and tagged numbers; build PDF and zip
python scripts/make_paper.py --check        # fail if anything differs from outputs/ (also run by pytest)
python scripts/make_paper.py --pages 1,3,5  # also render those pages to build/pages/ (git-ignored)
```

**How numbers are tied to the data.** As in the report, with LaTeX syntax: a number from the data
is written `\V{f.off.mp.att}{88.1}` (the macro prints `88.1` and ignores the key). Tables sit
between `% BEGIN:name` and `% END:name` and are generated by `src/trafficsense/report/paper.py`;
figures (`figures/*.pdf`, vector, 3.5 in wide) are drawn by
`src/trafficsense/report/paper_figures.py` from the same data as the report's figures, each with
a `.data.json` (the dashboard figure is a crop of `docs/screenshots/network_replay_viewport.webp`,
recorded by its sha256). The tools table (`tab_tools`) is generated too: package versions from
`requirements-lock.txt`, the Ollama version from the run records (it must be one value) and the
hardware from `outputs/reproducibility/fresh_clone.json`, so a changed version fails the check.
The check fails on any untagged number in the body, a stale table or figure,
a mismatch, a citation that is not one of the report's verified references, an abstract outside
150–250 words, a PDF or zip not built from the current sources, or more than 8 pages
(references included).
Registration numbers and the capstone term are identifiers, listed one by one in
`paper.IDENTIFIERS`; any other registration-number-shaped token fails the check.

**Build.** Tectonic (XeTeX) in `~/.local/bin`; the build also fails on overfull lines and
undefined references or citations. The source is plain ASCII and loads only standard packages
(`newtxtext`/`newtxmath`, `booktabs`, `graphicx`, `amsmath`, `cite`, `url`, `iftex`), so it should
also compile with pdfLaTeX, Overleaf's default; it has only been built locally with Tectonic.

## Word version (`paper.docx`)

`paper.docx` is the same paper in IEEE's own Word template
(`conference-template-letter.docx`, the "US letter" file from IEEE's
[conference template page](https://www.ieee.org/conferences/publishing/templates.html), kept here
unchanged). `python scripts/make_paper.py` builds it after the LaTeX (module
`src/trafficsense/report/paper_docx.py`), and `paper_docx.pdf` is what LibreOffice makes from it.
Nothing is typed again: the converter reads the refreshed `paper.tex`, so every number is the one the
LaTeX build tied to `outputs/`, and `make_paper.py --check` also verifies the Word file (Letter size,
two-column body, no placeholder or template text, every tagged number present, identifiers as listed,
references numbered 1..n, at most 8 pages, built from the current sources).

* **From the template:** page size and margins, the two-column body, Times 10 pt, the title, author,
  abstract, heading, caption, table and reference styles and their automatic numbering
  (I., A., Fig. 1., TABLE I., [1]) are IEEE's. `styles.xml` and `numbering.xml` in `paper.docx` are the
  template's, byte for byte.
* **Equations** are native Word equations (OMML). Figures are 300 dpi PNG renderings of
  `figures/*.pdf` (Word cannot embed a PDF page). References come from `refs.bib` through pandoc's
  citeproc with the IEEE CSL style used by the report (`docs/report/template/ieee.csl`).
* **What differs from the LaTeX PDF:** Word has no floats, so figures and tables sit where the source
  puts them; `FLOAT_SHIFT` in `paper_docx.py` moves a few of them by whole paragraphs (never across a
  heading, never reordering) to avoid gaps, tuned on LibreOffice's layout, so Word's own pagination may
  leave different gaps. Figures are raster PNGs, not vector. References use the CSL "IEEE" formatting
  rather than `IEEEtran.bst`. The Word file says "Keywords" (the template's word) where IEEEtran says
  "Index Terms", the title footnote is numbered 1 rather than a symbol, and equations are Word
  equations (rendered by LibreOffice with a substitute for Cambria Math). Table captions are in the
  template's small caps ("YOLOv8n" shows as small capitals). Page counts come from LibreOffice and can
  differ from Word's by a line or two. The package is Strict Open XML, as IEEE's template is; it was
  checked in LibreOffice and by the script, not in Word itself.
* The first-page footer text of the template (an ISBN / copyright line) is conference-assigned and is
  left empty.

## Before submitting: fill in the placeholders

At the top of `paper.tex`:

* `\EmailA` … `\EmailD`: the four authors' e-mail addresses (currently `{{EMAIL1}}` … `{{EMAIL4}}`).
* `\CapstoneID`: the capstone ID (currently `{{CAPSTONE_ID}}`; the diary reads `3328F4C8` but the
  handwriting is unclear, so confirm it first).

Then run `python scripts/make_paper.py` to rebuild the PDF and the zip, or edit on Overleaf.
The author block gives the city as Amaravati; check it against your university's style.

## Compiling on Overleaf

1. Overleaf → **New Project** → **Upload Project** → choose `paper_overleaf.zip`.
2. Open **Menu** and check **Compiler: pdfLaTeX** and **Main document: paper.tex**
   (Overleaf has `IEEEtran.cls` and `IEEEtran.bst` built in, so the zip does not include them).
3. Click **Recompile**. Overleaf runs BibTeX itself; if references show as `[?]`, recompile once
   more.
4. Fill in the placeholders (above) in `paper.tex` and recompile.

Edits made on Overleaf are not checked against `outputs/`. To keep the guarantee, copy the edited
`paper.tex` back here and run `python scripts/make_paper.py --check`.
